# Bomberman Land 2 — English Translation

An English translation of the Japanese GameCube game, by **Bojangles**, made with AI assistance and open to player corrections.

**Public test version: v0.1.0-beta.1.** Translation and layout testing are ongoing; this is not a fully verified final release.

## Included

- English startup, save/load, main-game and options menus.
- English story and NPC dialogue, park staff conversations and quizzes.
- Attraction instructions, help text, item names/descriptions and control prompts.
- BOMPAD menus, mail, attraction information and manga title lists.
- English text fitting, word wrapping and alignment adjustments, while retaining original colors, highlights and control icons where supported.
- Custom “Translated by Bojangles” opening splash and a creator message about AI during the Hudson logo.
- Original Japanese voices, music and sound effects.

## Download and install

Download the patch ZIP from [Releases](https://github.com/Bojaingles/Bomberman-Land-2-Translation/releases), extract it, and follow [INSTALL.md](INSTALL.md). You must provide your own matching, clean Japanese game ISO. No game ISO is included.

The patched ISO is exactly **1,459,978,240 bytes**, the same size as the original. Real-console compatibility is a project requirement, but **has not yet been verified on hardware**. Dolphin testing is ongoing.

## Remaining limitations

Manga artwork remains Japanese in the playable patch; English manga previews are not included. Japanese speech and movies are not fully subtitled, and text baked into some graphics/movies remains Japanese. Some text layouts and event paths still need playthrough testing. See [KNOWN_ISSUES.md](KNOWN_ISSUES.md).

## Report a problem

Use [GitHub Issues](https://github.com/Bojaingles/Bomberman-Land-2-Translation/issues/new/choose) for mistranslations, typos, untranslated text, clipping, crashes or other errors. Include the exact patch version, location/NPC, steps and a screenshot if possible. Japanese knowledge is not required. See [REPORTING_BUGS.md](REPORTING_BUGS.md).

Keep a backup of your memory-card saves. Stop the game completely before changing patch versions; old emulator save states can restore old game code.
